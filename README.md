# Небо Украины · аналитика канала @kpszsu

Дашборд по публичному Telegram-каналу Воздушных сил ВСУ [t.me/kpszsu](https://t.me/kpszsu): карта целей по областям, «сейчас в небе», официальные сводки (атаковано / сбито), распределение по дням и часам.

**Дашборд:** https://ukdc.github.io/kpszsu-dashboard/

## Как устроено

- `collector/kpszsu_collect.py` — читает публичную веб-версию канала (`t.me/s/kpszsu`), разбирает оповещения о целях и сводки, складывает документы по киевским суткам (последние 30 дней). КАБы и тактическая авиация исключены.
- `collector/build_site.py` — собирает сайт: `site/index.html` + один `data.json`.
- `.github/workflows/sync.yml` — каждые 30 минут (и по кнопке **Run workflow**) запускает сбор и публикует сайт на GitHub Pages. Состояние сборщика (кэш постов) хранится в ветке `data` одним коммитом без истории.

Цель = оповещение вместе с ответами-уточнениями о смене курса; подсчёт приблизительный. Цифры «атаковано / сбито» — из официальных сводок, предварительные.

Границы областей: [geoBoundaries](https://www.geoboundaries.org/) (CC BY 4.0).
